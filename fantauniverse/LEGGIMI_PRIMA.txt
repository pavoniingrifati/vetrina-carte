FANTABALLA UNIVERSE V4 — RESTYLING DEL SITO (non una semplice immagine)
=================================================================

HOME UNICA: index.html
La grafica è stata ricostruita sul sito vero (HTML, CSS e JavaScript):
- sinistra: menu Dashboard, Fantacalcio, Risultati e calendario, Classifiche, Database giocatori (Scout eliminato dal menu)
- colonna sinistra: classifica completa del campionato relativo al salvataggio
- pannello centrale: PROSSIMA PARTITA, data NEL GIOCO, countdown calcolato dallo snapshot del salvataggio, avversario e giornata
- colonna destra: risultati della sola squadra selezionata
- in basso: top media voto FM dei soli calciatori della squadra e capocannoniere della sola squadra
- selettore Fantaballa FC / Gotham City nel menu

DATI SEPARATI (IMPORTANTISSIMO)
- fantaballafc/: il database e tutti i file storici del salvataggio Fantaballa FC
- gothamcity/: il database e tutti i file storici del salvataggio Gotham City
La dashboard carica SOLO i JSON della cartella selezionata. Le rose esistenti,
i dati e le chiavi localStorage non sono state modificate.
La media voto mostrata è FM averageRating, NON la fantamedia completa.
Per le medie sono ammessi solo giocatori con voto in almeno il 25% delle
partite della squadra (minimo 2) per evitare valori fuori scala da 1 sola presenza.
Non vengono inventate informazioni non contenute nel save come stadio o meteo.

PROVA IN LOCALE (Windows)
1. Estrai lo ZIP in una cartella mantenendo la struttura.
2. Avvia Avvia_Dashboard.cmd.
3. Apri http://localhost:8000/ oppure http://localhost:8000/index.html.
4. Cambia universo dal menu laterale.

PUBBLICAZIONE
Fai un backup dei file online e carica i CONTENUTI dello ZIP alla radice
(repository GitHub Pages), non lo ZIP stesso. Conserva le cartelle.
Il caricamento via doppio clic su index.html (file://) non basta a leggere i JSON.
Le pagine interne del Fantacalcio, Campionato e Database sono quelle esistenti:
questa versione è il restyling della dashboard, non ancora delle pagine interne.
