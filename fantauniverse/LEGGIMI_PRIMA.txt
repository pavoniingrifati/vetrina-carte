FANTABALLA UNIVERSE - DASHBOARD UNIFICATA v3
====================================================

AVVIO
  1. Estrai tutto lo ZIP, mantenendo intatta la struttura delle cartelle.
  2. Apri Avvia_Dashboard.cmd (Windows) oppure avvia un server HTTP nella cartella dello ZIP:
       python -m http.server 8000
  3. Apri http://localhost:8000/index.html
  4. Passa fra Fantaballa FC e Gotham City dal selettore CAMBIA UNIVERSO a sinistra.

LA DASHBOARD E' UNICA, I DATABASE NON SONO COMBINATI
  fantaballafc/  : save Super Lega Fantaballa FC s3.fm - 27/12/2025
    - 48 club, 2.668 giocatori, 647 gare disputate
  gothamcity/    : save Super Lega Gotham City S2.fm - 09/08/2025
    - 48 club, 2.897 giocatori, 165 gare disputate

  index.html importa soltanto i JSON della cartella corrispondente al mondo selezionato.
  Ogni mondo ha i suoi league_standings.json, league_results.json, league_events.json,
  players_stats.json, players_skills.json, catalogo_invio.json e clubs_data.json.
  Ogni mondo mantiene il proprio builder della rosa e le proprie chiavi localStorage:
   fantaballafc_rose_2025_v1 e gothamcity_rose_2025_v1.
  Non si mescolano quotazioni, squadre, classifiche, giocatori o risultati.

PAGINE
  index.html                 dashboard unificata (pagina d'ingresso)
  fantaballafc/fantacalcio.html  builder Fantaballa FC
  gothamcity/fantacalcio.html    builder Gotham City
  <universo>/campionato.html    risultati/classifica/statistiche
  <universo>/scouting.html      database dettagliato giocatori
  <universo>/index.html         dashboard autonoma di compatibilita'

NOTE
  I dati dei salvataggi sono storici, non in tempo reale.
  Le medie fantacalcio possono essere parziali secondo i limiti dell'estrattore originale.
  Non usare il doppio clic su index.html per caricare i dati: il browser blocca fetch JSON
  tramite file://. Si raccomanda un server locale o hosting web.
  Sono conservati originali per ogni universo i relativi file, Google Sheets script e admin.
