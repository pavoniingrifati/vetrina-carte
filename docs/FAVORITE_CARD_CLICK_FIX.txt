FIX CARTA PREFERITA

Problema:
- Le carte del profilo erano tag <a> verso ./index.html?q=...&card=...
- quindi cliccando l'immagine il browser apriva /docs/index.html
- il controllo Preferita risultava poco intuitivo e poteva sembrare non funzionare

Correzione:
- la carta non è più un link
- clic sulla carta = imposta/rimuove la carta preferita
- pulsante Preferita spostato sotto la carta
- la carta scelta viene evidenziata in oro
- "Apri collezione" punta a https://fantaballa.it/FUT/cards/
- se Firebase rifiuta il salvataggio, viene mostrato un messaggio che ricorda di pubblicare firestore.rules

IMPORTANTE:
Il file firestore.rules incluso nel progetto autorizza favoriteCardId e featuredAchievementIds.
Caricare i file sul server NON aggiorna automaticamente le Rules del progetto Firebase:
le Rules vanno pubblicate anche dalla console Firebase / deploy Firebase.
