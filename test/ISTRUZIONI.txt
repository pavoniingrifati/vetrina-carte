FANTAUNIVERSE - VERSIONE AUTONOMA GITHUB PAGES

PUBBLICARE:
1. Crea un repository GitHub (es. FantaUniverse).
2. Carica TUTTI i file e le cartelle del progetto (anche .github).
3. Impostazioni repository > Pages > Build and deployment > Source: GitHub Actions.
4. Fai commit su branch main. L'azione pubblica automaticamente il sito.
5. Il link sara https://TUONOME.github.io/FantaUniverse/ .

IN LOCALE:
Installa Node.js LTS. Apri la cartella nel terminale e usa:
 npm install
 npm run dev
poi apri l'indirizzo localhost indicato.

ALTERNATIVA SENZA NODE (SERVE UN SERVER LOCALE):
La cartella SITO_GIA_COMPILATO contiene la build: caricala su un hosting statico o avvia un server HTTP locale da quella cartella. Non aprire index.html con file:// perche' il browser blocca i fetch dei JSON.

Questa e' una dashboard di consultazione con dati JSON statici. Non include login, database remoto, funzioni server o servizi proprietari Base44.
Le rotte usano #/ per funzionare su GitHub Pages senza configurazioni aggiuntive.
