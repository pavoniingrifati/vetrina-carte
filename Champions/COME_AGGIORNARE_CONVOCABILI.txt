POTENZIALI CONVOCATI - AGGIORNAMENTO DATABASE

Pagina pubblica: https://fantaballa.it/convocabili.html
Database: data/convocabili.json

Per aggiungere un utente, aggiungi un oggetto JSON prima della parentesi finale ]:

  {
    "nome": "NuovoUtente",
    "probabilita": 50,
    "motivo": "Motivo",
    "club": "Roma"
  }

Regole:
- probabilita: numero da 0 a 100, senza %;
- club può essere vuoto: "club": "";
- motivo è testo libero;
- non serve modificare convocabili.html;
- la pagina legge il JSON senza cache, quindi gli aggiornamenti diventano disponibili appena il file viene sostituito sul server.
