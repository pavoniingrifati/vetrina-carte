# Fantallenatore: app installabile

Pulsante Installa Fantallenatore nella home mobile. Richiesta nativa nei browser che la supportano, istruzioni Safari su iPhone e istruzioni manuali come alternativa. Manifest e icone app; apertura standalone e copia offline completa del gioco. Aggiornamenti scaricati in attesa: si applicano dalla home senza ricaricare una partita in corso. Cache circoscritta alla cartella del gioco; salvataggi locali invariati.

Contiene solo Fantallenatore, con tutti gli aggiornamenti precedenti. Pubblica l intera cartella sul sito HTTPS. Dettagli in PWA_INSTALLAZIONE.md.

Verifica: 87 test core, build PWA, icone e scope sotto sottocartella; test Chromium di apertura offline con carriera salvata, richiesta installazione simulata, istruzioni iPhone, aggiornamenti e storage offline bloccato. Installazione su telefoni fisici non verificata.
