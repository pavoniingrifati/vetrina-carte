# Fantallenatore: campo mobile corretto

Rimosso il minimo di 450 pixel su mobile per i moduli con reparti da cinque giocatori. Campo proporzionato allo spazio disponibile, giocatori con un piccolo margine tra le posizioni. Verificati tutti i moduli standard vuoti e compilati a 320, 360, 390, 430 pixel e 844 pixel in orizzontale. Test browser estesi ai moduli 3-5-2 e 4-5-1 e al controllo della larghezza del campo.

Solo cartella Fantallenatore, con tutti gli aggiornamenti precedenti. Fai un backup prima di sostituire la cartella.
