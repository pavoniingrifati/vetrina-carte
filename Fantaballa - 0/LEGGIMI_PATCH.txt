PATCH — PUNTEGGIO DIRETTORE SPORTIVO

Questa patch va applicata alla versione più recente di Fantaballa con la modalità Direttore Sportivo.

COME APPLICARLA
1. Estrai il contenuto dello ZIP nella cartella principale del sito Fantaballa.
2. Conferma la sostituzione dei file esistenti.
3. Aggiorna obbligatoriamente la Web App Google Apps Script seguendo AGGIORNA_GOOGLE_SCRIPT.txt.
4. Avvia AVVIA_ANTEPRIMA.bat dalla cartella principale per provarla offline.

FORMULA CLASSIFICA
Punteggio DS = (Punti finali x 10 + Influenza rimasta x 80) x coefficiente difficolta

COEFFICIENTI
- Posizione prevista 1-3: Facile x1,00
- Posizione prevista 4-7: Normale x1,15
- Posizione prevista 8-12: Impegnativa x1,35
- Posizione prevista 13-16: Difficile x1,60
- Posizione prevista 17-20: Estrema x1,90

FILE AGGIORNATI
- direttore-sportivo.html
- assets/director/director.js
- assets/director/director.css
- classifica.html
- privacy.html
- google-apps-script/invio_vittoria.gs
- AGGIORNA_GOOGLE_SCRIPT.txt

NOVITA
- difficolta automatica calcolata dalla forza iniziale della rosa;
- coefficiente visibile nel briefing e durante la missione;
- schermata finale con formula completa e Punteggio DS;
- invio di difficolta, Influenza rimasta e Punteggio DS;
- Google Apps Script ricalcola il punteggio lato server;
- classifica ordinata per Punteggio DS;
- compatibilita con i vecchi risultati: il browser ricalcola i campi mancanti.

IMPORTANTE
La modifica locale del file Google Apps Script non aggiorna la Web App online. Segui AGGIORNA_GOOGLE_SCRIPT.txt e crea una nuova versione del deployment esistente senza cambiare URL.
