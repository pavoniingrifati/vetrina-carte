PACCHETTO FANTABALLA CON PAGINA SCOUTING

File inclusi:
- index.html: builder rosa aggiornato con bottone "Scouting giocatori"
- scouting.html: nuova pagina per consultare skill, CA, costo, ruolo e club
- players_stats.json: database giocatori usato dal builder
- players_skills.json: database completo skill giocatori
- clubs_data.json: colori club + struttura pronta per quote e probabili formazioni

Istruzioni:
1. Carica tutti questi file nella stessa cartella del sito.
2. Apri index.html: trovi il bottone "Scouting giocatori".
3. Apri scouting.html: puoi filtrare per club, ruolo e profilo.
4. Quando avrai quote e probabili formazioni, si aggiorna solo clubs_data.json.

Nota:
Le quote/favorite stampa e le probabili formazioni NON sono state inventate:
nel file attuale sono predisposte come "Da inserire".
Aggiornamento: nel builder rosa i ruoli sono mostrati solo in forma semplificata P / D / C / A. Le posizioni FM dettagliate restano disponibili nella pagina scouting.

Aggiornamento traduzioni:
- Ruoli/posizioni della pagina scouting tradotti in italiano.
- Nomi caratteristiche tradotti seguendo le diciture italiane di Football Manager, come Colpi di testa, Contrasti, Controllo di palla, Intuito, Posizione, Massima elevazione, ecc.
- Il builder rosa mantiene i ruoli semplificati P / D / C / A.
